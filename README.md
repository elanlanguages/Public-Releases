# Public Releases

Official public release and automatic-update channel for ELAN Languages Windows applications.

This repository contains compiled installers and machine-readable update metadata only. Application source code is maintained in separate private repositories.

## Download page

https://elanlanguages.github.io/Public-Releases/ lists the applications with a link to their latest installer.
Permanent download links, which always point to the newest version: `https://elanlanguages.github.io/Public-Releases/download.html?app=<id>` (`elan-chat`, `xtrf-for-windows`, `swornfinder`). XTRF Tools and In-House Tools are browser extensions: their cards link to the store listings. In-House Tools' Firefox button links to the newest `.xpi` in the `in-house-tools-latest` release and stays hidden until that release has one.

The site lives in `docs/` (GitHub Pages, branch `main`, folder `/docs`). Add or edit applications and extensions in `docs/apps.js`.

## Update channels

- `elan-chat-latest` — ELAN Chat for Windows
- `xtrf-tools-latest` — XTRF Tools
- `xtrf-for-windows-latest` — XTRF for Windows
- `swornfinder-latest` — SwornFinder

Applications may require an authorized ELAN Languages account.
